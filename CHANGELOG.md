# Изменения

## 0.1.0 — 1 октября 2026 года

Первый публичный выпуск JobScheduler для Windows 10/11 x64.

- Единый установщик, создание главного администратора, фоновая служба и значок управления.
- SQLite, резервное копирование при обновлении, восстановление прежней базы или создание новой базы с архивированием старой папки.
- Веб-интерфейс и встроенная документация с примерами Python и TypeScript.
- Процессы на компьютере, в контейнерах и в смешанном режиме; граф зависимостей, расписания, параметры и результаты.
- Роли user/operator/admin, заявки и проверки, назначение нескольких операторов, уведомления при открытом интерфейсе.
- Администратор может создать процесс для другого пользователя.
- История запусков, потоковые логи, переключатели активности и автообновления.
- Режимы сети: этот компьютер, локальная сеть с HTTPS, интернет через домен и HTTPS.
- Адаптивная разметка, иконка приложения и компактные списки заявок.

Автоматическое обновление и цифровая подпись издателя в эту версию не входят. Сведения о проверенных сценариях и ограничениях приведены в README и инструкции установки. Тестовые проекты не включены в этот релиз.
