# JobScheduler

Бесплатный планировщик связанных задач для **Windows 10/11 x64** с веб-интерфейсом. Задачи могут выполняться на компьютере, в Docker или в смешанном режиме. Поддерживаются расписания, зависимости задач, история запусков, логи и результаты.

**[Скачать установщик JobScheduler 0.1.0](https://github.com/aleksey-iwanow/JobScheduler/releases/download/v0.1.0/JobScheduler-0.1.0-win-x64-Setup.exe)** · [Все версии](https://github.com/aleksey-iwanow/JobScheduler/releases)

## С чего начать

1. Скачайте установщик из Releases и запустите его на Windows-компьютере, где будут выполняться задачи.
2. При новой установке создайте главного администратора в мастере установки.
3. Откройте JobScheduler через значок приложения. По умолчанию адрес — `http://127.0.0.1:8080`.
4. Войдите и откройте встроенную документацию: в ней есть полные примеры Python/TypeScript, настройки процессов, расписания и диагностика.
5. Создайте пользователей и процессы. На компьютере задачи запускаются внешним runner; для контейнерных задач установите Docker отдельно.

Пользователям других устройств не нужен установщик: они работают в браузере. Каждый установленный экземпляр имеет собственную SQLite-базу. Издатель не предоставляет общий сервер и не хранит базы установок.

## Возможности

- Зависимые задачи, параметры и результаты предыдущих шагов.
- Python и TypeScript через [открытые SDK](https://github.com/aleksey-iwanow/jobscheduler-sdk), другие языки через протокол задач v1.
- Ручной запуск и расписания, история и логи в реальном времени.
- Роли `user`, `operator`, `admin`, проверка заявок пользователей и назначение операторов.
- Создание администратором процессов для других пользователей.
- Фоновая служба Windows, работа без постоянного входа пользователя.
- Доступ только с компьютера, по локальной сети с HTTPS или через домен и HTTPS из интернета.
- Обновление установкой следующей версии поверх предыдущей с сохранением данных.

## Важно перед установкой

**Служба и одобренные задачи на компьютере работают от LocalSystem с высокими системными правами.** Проверяйте код и параметры перед одобрением; роли operator/admin выдавайте только доверенным людям. Проверка заявки не является песочницей.

Для доступа из интернета нужны домен, DNS и настройка роутера при наличии NAT. Для локального HTTPS клиентским устройствам нужно доверять сертификату вашей установки. Не открывайте внутренние порты API и Next.js наружу.

Установщик не подписан сертификатом издателя: Windows может показывать предупреждение SmartScreen. Проверяйте источник загрузки и SHA-256 из релиза. Цифровая подпись и автоматическое обновление в версии 0.1.0 отсутствуют.

Поддержка Windows 10/11 x64 заявлена; отдельные сценарии установки и обновления на чистых машинах, публичный HTTPS и запуск после выхода из Windows требуют проверки в вашем окружении. Работа задач с интерактивным рабочим столом и устройствами пользователя из службы не гарантируется. Docker и языковые окружения устанавливаются отдельно.
