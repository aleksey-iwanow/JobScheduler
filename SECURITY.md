# Безопасность

Для сообщения об уязвимости напишите на **mailggkk@gmail.com**. Не публикуйте в открытом Issue пароли, токены, базы, конфиденциальные логи или подробности, позволяющие атаковать чужие экземпляры.

JobScheduler 0.1.0 запускает службу и одобренные host-задачи от LocalSystem. Роли operator/admin дают возможность выполнять доверенный код с высокими правами. Модерация заявки — проверка конкретных настроек, а не изоляция процесса.

Перед открытием доступа из интернета настройте HTTPS и надёжные пароли. Не открывайте внутренние порты API и Next.js. Пользуйтесь официальными установщиками из Releases, проверяйте SHA-256 и храните резервные копии.

Подпись кода и автоматическое обновление пока отсутствуют. О новых версиях сообщается в Releases; установщик новой версии запускается вручную.
